TheTobsDev Site Plan

Individual project planning document for WDD231 — Web Frontend Development II

Site Name

TheTobsDev

This name combines my nickname “Tobs” with “Dev” to clearly communicate a personal web development brand. It matches my existing GitHub and LinkedIn identity, is easy to remember, and tells visitors immediately that the site focuses on software and web development work.

Optional domain: thetobsdev.dev

Site Purpose

TheTobsDev is a developer portfolio website that showcases my web development projects, technical skills, and professional background. The site provides a central hub where employers, collaborators, and classmates can review my work, learn about my experience, and contact me for opportunities.

The site will include:

  • A home page introducing my brand and featured projects
  • A projects page with dynamically loaded project cards from JSON data
  • An about page describing my background, goals, and education
  • A contact page with a form for inquiries and collaboration requests

Scenarios

Questions a target visitor might ask when using the site:

  • What web development projects has Tobiloba built, and what technologies did he use?
  • How can I contact Tobiloba for freelance work, internships, or collaboration?
  • What skills, tools, and certifications does Tobiloba have as a frontend developer?

Color Scheme

The palette uses deep navy for structure, warm gold for emphasis, and light neutrals for readability. These colors are applied throughout this site plan document.

#14213d — Oxford Blue

Used for the header, footer, primary headings, navigation bar, and wireframe outlines.

#fca311 — Selective Yellow

Used for links, section underlines, accent highlights, buttons, and call-to-action areas.

#f5f7fa — Light Gray

Used for the page background and secondary content panels.

#ffffff — White

Used for content cards, wireframe blocks, and readable content surfaces.

#222222 — Charcoal

Used for body text and paragraph content to maintain strong contrast on light backgrounds.

Typography

Poppins — Headings

Applied to page titles, section headings, navigation labels, project card titles, and wireframe labels. Poppins gives the site a modern, professional appearance.

Inter — Body Text

Applied to paragraphs, lists, form labels, footer text, and project descriptions. Inter is highly readable on screens and works well at smaller sizes on mobile devices.

Wireframe

Home page layout sketches showing content relationships for mobile and larger viewports. Boxes represent content areas, not final design or copy.
